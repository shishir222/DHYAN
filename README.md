
# DHYAN — Focus & Productivity Chrome Extension



DHYAN is a minimalist Chrome extension designed to help you stay focused, reduce distractions, and build better study/work habits using smart timers, focus sessions, and break management.

## ✨ Features

### 🎯 Focus Mode
- Start focused study/work sessions with customizable timers.
- Helps eliminate distractions and maintain deep work.
- Tracks your productivity time.

### ⏱️ Floating Focus Timer
- A small movable timer appears inside the webpage.
- Keeps your focus session visible without interrupting your workflow.
- Drag it anywhere on the screen.

### 🧘 Smart Break System
- Automatically reminds you to take breaks after long focus sessions.
- Provides short recovery periods to avoid burnout.
- Encourages healthy work cycles.

### ⚙️ Customizable Settings
- Adjust focus duration.
- Configure break duration.
- Enable/disable features according to your workflow.

### 🌙 Minimal Interface
- Clean and distraction-free design.
- Designed for students, developers, and professionals.
- Lightweight and fast.
